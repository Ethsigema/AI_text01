## 本批目标，不是当前完成声明

在暗潮战略专家有限组合中，让已经通过真实 hand→board 事务认证、未增益的单个普通熔岩潜伏者（BG23_009，2/5，kept=0）沿原生 sale 执行器真正出售。原执行器负责移除、原金币收入、原库存归还及 sold 统计，新 helper 只约束原操作上下文、观察效果并撤销准确旧实例的私有入场记录，不重复付钱、返还库存或生成 UID。

成功需验证原对象离开所有持有区域、其它战队与手牌对象和值不变、唯一原库存 +1、金币 +1、sold +1、UID 与 RNG 不变，并继续实际暗潮 EOT/下一招募。部分失败不能假装回滚：必须保留原错误与已经发生的变化，不能给已离场旧对象留下可复用许可。上下文、复制/错 owner/重播、退役旧 UID 等检查应有独立证据；未实际触发的失败路径不得冒称真实对局覆盖。

本批不开放暗潮活动时重新购买 Lava；该路径另有购买投影门禁。普通 Lava 的永久保留涉及 Mini 来源、原生 Waiting/token 与附魔生命周期，留在研究报告中，不把原 Game 已有逻辑说成本批新增。金色、多 Lava、外来目标塑造法术、6 级后 EOT、英雄或其他新机制、完整对局/UI/保存载入与全量卡池均不扩大验收。

## 清理和备份边界

用户授权仅清理可恢复的非备份冗余。已取得共同运行锁，分别重新读取 Lava 与 Tier6 两份测试 run_tree 及各自等价 immutable restore，四树均完整 SHA/路径/字节一致、无独有文件。仅删除这两份测试运行副本，释放 3,267,821,568 字节；所有源包、早回执、最终回执、审计、失败证据、日志、候选与不可变恢复树保留。详见 CLEANUP_PREFLIGHT.json 和 CLEANUP_EXECUTED.json。

新批次实际重新下载完整固定依赖并恢复 batch14；不为重复验证再建立一棵旧 Lava 基线树。旧 Lava 前像由上述独立副本核验及固定下载的 SOURCE_MAP 对照证明，不能称本批重新恢复旧 Lava。新源码达到冻结阶段后，先发布明确未验收的 batch14 累积增量，再从固定提交实际下载并独立重建新源码、逐文件核验，然后才运行耗时 Game。

实际测试使用明确披露的拥有暗潮之前的 Coin 筹资 fixture，不直接注入目标 Lava/暗潮、live RNG、库存、等级、token 或 UID。旧批次 2,974 项通过是前像证据，不代替本批变化后的验收。
