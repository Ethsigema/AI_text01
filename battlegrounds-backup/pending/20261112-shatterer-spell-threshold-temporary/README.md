## 实际修复

旧候选中，普通碎地者在施放原生“迷你三叉戟”后获得合法的临时 +2 攻击，但之后打出纳迦会被 `shatterer_attached_or_temporary_layer_partial` 错误拒绝。已在未改动的旧候选代码上通过完整 Game/Catalog、真实工厂/入手和公开 apply_command 复现，失败日志保留。

新修改只涉及 `core/shatterer_host.gd` 和其 `shatterer_sources.gd` 哈希钉值。允许原生三字段、非负整数、无关键词的加法临时属性层，并检查字段形状、总和溢出和扣除后的有效本体。仍拒绝关键词、额外标记、浮点/负值、附加组件等未覆盖组合。不改 Game、Catalog、Combat、_buff、临时层写入或原生到期函数，不把永久成长混入临时账本。

另新增两份回归脚本及说明。相对 11 月 11 日候选：修改 2 文件、新增 3 文件、删除 0。包为相对第 14 批已合并基线的累积候选增量，包含之前候选必需的文件；无需先叠加旧碎地者候选。
