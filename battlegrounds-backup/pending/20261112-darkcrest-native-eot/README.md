Godot4.6.3，完整Game/Catalog/Combat；两个原艾德温受限房间。测试用真实酒馆币筹资，升级、刷新、购买、出牌、施法、双方结束回合均走公开apply_command，不直接写金币、等级、施法数、战队、库存或随机数。

- 两房间最终 113 项集成检查通过。1/2/3级分别实际收到BG36_921/BG23_009/BG23_007；各自仅扣一次对应库存，UID由原工厂分配，原生施法计数与消耗正确。
- 每轮真实完成战斗并进入下一招募回合，原生调度每来源只成长一次。满手和双来源测试验证各自等级快照、等待顺序、自然到期及新票据。
- 完整4级启用池仍在抽牌前明确拒绝；拒绝不消费令牌，不改变手牌、库存、RNG、UID或施法计数。继续超出受限等级时明确拒绝，不悄悄钳制或称官方上限为4。
