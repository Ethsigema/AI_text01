# 普通 Mini → Lava 永久加成隔离候选：原生键类型修复

本批是首次失败 Mini 候选的最小修复，不是恢复丢失工作树，也不是新全量内容或默认版验收。

前像来自固定源码提交 `517a547eebad779a65189fa67b845f82d5ec6886` 的独立远端恢复树，27,982 文件、1,550,853,439 字节；前像地图 SHA256 `302328d7278ce8902ceba79d4532fa564c9f17022e76c0bf6b7165ea442becca`。该前像的实际 Game 失败在 `public_original_mini_play_and_waiting_grant`，错误 `darkcrest_mini_full_native_child_shape_required`，证据已发布于 `9d6ad450f4c5ad287b49612c9c2ba3de399cc67b`。前像可恢复不等于玩法已通过。旧失败源码、恢复树、日志与备份全部保留。

最小逻辑修复仅将完整原生衍生法术预期字典的 `max_health` 与 `expires_at_end_turn` 两键，改成与原生工厂、Waiting 一样的点赋值构造，保留其 StringName 键类型。字段集合、值、严格比较器和权限范围均未放宽。实际工厂诊断确认字段值相同，但未记录键类型；键类型问题的证据为实际源码与独立字典语法探针，后续真实运行必须另外确认。纯测试原有手写夹具与错误预期同源，先前 340 通过不构成原生成功证明。

本批替换当前测试夹具以使用原生键构造，新增错误 String 键拒绝检查。冻结前仅运行纯合同 344 项，0 失败，未启动 Game，源码前后全量 SHA 一致。新真实矩阵在同一个已启动 Game 中加入不分配 UID、不入区域、不签凭证的工厂预览及全部顶层/基础键类型记录；预览不是来源凭证，之后仍须实际 public play → Waiting 发出原对象。

目标范围保持有限：单普通 Mini、单普通 Lava、普通暗潮在场；两轮首个原生 Trident 的永久 +2，3 次非空实战，原生 kept 重置，以及第 3 轮未使用法术过期和下一轮重发。原永久效果已存在，本批是这条流程的权限兼容。未覆盖第 2 Mini、同轮第 2 cast、其他目标、金色、满手、强化后出售/重买、暂停的空位链或全量饰品。不提升默认卡池，不增加英雄和范围外机制。
