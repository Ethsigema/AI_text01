## 边界和原因结论

此前完整Game失败时进程收到SIGKILL；两次记录到最大RSS约2.71–2.77GiB，进程控制器记录process_exit而非超时或主动终止。缺少内核/cgroup事件证据，不能断言OOM、容器限额或平台终止原因。

指纹阶段对30.9MB raw JSON建立完整文本再哈希，可能有约百MB级瞬时字符缓冲；顺序读取的87.3MB不能视为同时存活。57个evidence结果跨摄入存活，但关联JSON源体量约5.7MB，尚未证明它们比整份raw parsed graph更大。850个preload与约46.5MB core源码的固定成本仍未分阶段量化。

数据探针没有调用所有来源验证器、额外overlay/registry、完整catalog脚本编译、Game、存档/恢复、回放或希望信使同场效果。上述均未验收。只读审查不是运行测试；旧女妖战斗通过不是新catalog完整验证。
