## 数值语义不是普通Python相等

真实当前GD的Exact.same允许数值int/float等值，拒绝bool/number混同；混合大整数与浮点会按float64转换，而int/int仍按整数精确比较。字典键还区分bool/int/float类型。

通过实际Godot分别记录输入类型、整数十进制和浮点的原始64位表示，形成33项可重现对照，包括2^53附近、int64边界、正负无穷、NaN、嵌套值和键类型。保留浮点位模式，避免把大数十进制字面量的解析误差误判成比较规则。

修正使用有符号int64/float64语义。超出int64的Python整数失败关闭，不尝试溢出转换；现有来源均为JSON形状对象。没有声称覆盖任意Godot Variant、任意Python对象、同一字典中的异质碰撞键或NaN字典键。
